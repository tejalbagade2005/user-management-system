# 📖 About The Project

This project is a **Full Stack User Management System** developed during my **IT Vedant Internship** using **React.js**, **Spring Boot**, **Spring Security**, **JWT Authentication**, and **MySQL**.

The application provides a secure authentication system where users can register, log in, log out, and access a protected dashboard. All user data is stored and managed in a MySQL database using REST APIs.

# 📡 API Endpoints

| Method | Endpoint | Description |
|---------|----------|-------------|
| POST | /api/auth/register | Register User |
| POST | /api/auth/login | Login User |
| POST | /api/auth/logout | Logout User |
| GET | /api/users | Fetch Users |
